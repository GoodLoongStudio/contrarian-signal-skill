# 公开人物回测规范 / Public Person Evaluation

本文件用于避免把市场观点回测变成对真人的声誉评价。

## 分析对象

可以分析：

- 投资博主；
- 交易员；
- 分析师；
- 财经自媒体；
- 公开社交账号。

前提是分析依据来自其公开可访问内容。

## 只评价可观察行为

允许：

- “在本样本中，90-100 明确度的方向观点反向命中率为 62%”；
- “ACTION 与 OPINION 的历史结果明显分化”；
- “该账号在 BREAKOUT_CHASE 风格下的样本更容易出现短期反向结果”。

避免：

- “这个人不懂投资”；
- “这个人骗人”；
- “这个人永远是反指”；
- 由回测结果推断智力、人格、诚信或职业资格。

## Benchmark 案例

仓库可保留真实公开账号作为方法测试案例，但必须明确：

- 仅用于验证方法是否能处理不同风格；
- 不代表对其人格或专业能力作整体评价；
- 结果只对应具体时间窗、可访问语料、固定观察周期和公开行情；
- 数据覆盖不完整时必须标记 PARTIAL。

首批方法基准包括：

- 微博：`峰哥亡命天涯` —— 用于测试 ACTION、快速反向、追涨/清仓等历史行为分类；
- X：`@aleabitoreddit`（Serenity）—— 用于测试长期 THESIS 与短期 ACTION/TIMING 是否分化。

## 用户要求“是不是反指”时

可以回答该问题，但最终表述应落在历史统计：

> 在当前可验证样本和固定观察周期下，反向命中率为 X%；样本强度为 Y。这个结果是历史校准，不代表未来可以机械反向交易。

不要把统计标签扩展成人身标签。
