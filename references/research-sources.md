# 研究来源规范 / Research Sources

本 Skill 只基于公开信息工作，并优先使用可复核来源。

## 社交平台原始内容

优先级最高的是目标账号自己的原始帖子、视频、直播回放或可验证存档。

需要保存：

- 发布时间；
- 平台；
- 原始 URL / 稳定 ID；
- 原文或忠实摘录；
- 是否为本人发言、引用、投稿或转述；
- 编辑/删除状态（如能确认）。

## 历史价格

价格验证应优先使用：

- 交易所或官方市场数据；
- 可靠金融数据源；
- 可复核的日线/分钟线历史行情。

记录 entry/evaluation timestamp、price、return_pct 和数据源。

禁止：

- 看到结果后选择最有戏剧性的盘中高低点；
- 用不同来源中对自己结论最有利的那个价格；
- 在没有可靠价格源时凭记忆打分。

## 二手来源

财经媒体、采访、新闻报道和研究文章可用于：

- 找线索；
- 补原帖无法访问时的上下文；
- 交叉验证时间与措辞。

但如果二手来源无法确认是否为本人原话，必须降低 attribution/evidence 等级。

## 搜索摘要与社交转述

搜索结果摘要、论坛、粉丝整理只能作为检索入口。

它们不能单独支撑：

- 高置信 ACTION；
- 高置信 OPINION；
- 对真实人物的强结论。

## 覆盖率

默认目标是前 365 天的“尽可能完整可访问语料”，而不是几个最出名的案例。

如果存在：

- 平台分页限制；
- 删除帖；
- 登录墙；
- 搜索索引缺口；
- 无法访问的月份；

必须标记 `PARTIAL`，并在报告里说明缺口。

## 当前信息

如果用户要求把历史画像用于“现在/最新”的讨论，必须重新核验：

- 当前观点原文；
- 当前价格；
- 最新公告/事件；
- 当前市场环境。

历史分数本身不能替代当前信息核验。
