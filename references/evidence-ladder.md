# 证据等级 / Evidence Ladder

用于给每条历史观点、身份归属和行情验证证据分级。

## Strong / 强证据

优先用于高置信结论：

- 原始社交平台帖子、原始视频/直播记录或可验证存档；
- 交易所、监管机构、公司公告和官方投资者材料；
- 可靠历史行情源的时间戳价格；
- 经可信存档服务保存、能够确认发布时间与原文的历史页面。

## Medium / 中等证据

用于交叉验证：

- 可信财经媒体对原话的直接引用；
- 高质量采访、播客文字稿；
- 专业数据服务对价格或事件的二次整理；
- 多个独立公开来源一致指向同一事实。

## Weak / 弱证据

只能作为线索，不能单独支撑高置信评分：

- 二手截图；
- 无法确认原始上下文的转发；
- 粉丝总结、论坛搬运；
- 搜索摘要；
- “大家都知道他当时说过”之类无法追溯的说法。

## 评分要求

每个进入最终分数的记录，至少应满足：

- 观点/动作本身：Strong 或 Medium；
- attribution：足以判断为 TARGET；
- 价格验证：可复核；
- 方向与观察周期：在查看结果前冻结。

如果核心证据只有 Weak：

- 保留在候选语料；
- 标记 `UNVERIFIABLE` / `UNSCORABLE` / `UNCERTAIN`；
- 不为了增加样本量而强行计分。

## 证据标签

报告中优先使用：

- **Strong**：原始来源或权威一手资料；
- **Medium**：可信二手来源且可交叉验证；
- **Weak**：只适合作为线索；
- **Needs checking**：重要但尚未完成核验。

## 冲突处理

当来源冲突时：

1. 原始来源优先于二手摘要；
2. 带时间戳的原始页面优先于后来的回忆；
3. 明确原话优先于第三方概括；
4. 若无法解决冲突，则降低 attribution/evidence confidence 并排除评分。
